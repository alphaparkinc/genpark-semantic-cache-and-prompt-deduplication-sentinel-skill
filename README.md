# genpark-semantic-cache-and-prompt-deduplication-sentinel-skill

Evaluates prompt similarity via n-gram shingling, token hashing, and min-hash signatures to serve deterministic cached agent responses and eliminate redundant LLM calls.

100% Python Standard Library implementation with zero external dependencies.
